## Descrição do Portfólio
Este projeto consiste no desenvolvimento e evolução de um portfólio pessoal responsivo, criado com o objetivo de apresentar minha trajetória acadêmica, habilidades técnicas e projetos desenvolvidos no curso técnico de Desenvolvimento de Sistemas.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização personalizada e efeitos visuais.
* **Bootstrap:** Framework para responsividade e componentes de interface.
* **Git & GitHub / GitHub Pages:** Versionamento de código e hospedagem.

## Explicação do Funcionamento do Projeto
O site é estruturado em página única com navegação por menu superior, contendo:
1. **Menu de Navegação:** Fixo no topo com links funcionais.
2. **Seção de Perfil:** Apresentação profissional e área de atuação.
3. **Seção de Projetos:** Exibição em cards dos trabalhos práticos realizados (Portfólio, Landing Page e Sistemas em Python).
4. **Seção de Contato:** Canais diretos de comunicação.

## Descrição do Recurso Novo Adicionado
Foi desenvolvida uma seção interativa com efeitos visuais e estilização personalizada nos cards de projetos, aprimorando a experiência do usuário ao navegar pela página.

-foi adicionada uma animação de transição e elevação nos cards de conteudo do site.

## Explicação de Como Esse Recurso Foi Implementado
- **No HTML:** Utilização de classes de layout e cards do Bootstrap.
- **No CSS:** Aplicação de estilizações e transições visuais para destacar os elementos quando o cursor passa por cima.
